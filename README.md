## ramgthunder12 (방채담) 개발 기능 상세 설명

ramgthunder12는 본 프로젝트에서 **Backend API 개발**과 **Frontend 화면 구현**을 담당하였으며, 총 12건의 커밋을 통해 아래의 기능들을 구현하였습니다.

---

### 1. 여행 루트 생성 기능 (`#11` — `cda3e80`)

**목적:** 사용자가 새로운 여행 루트(일정)를 작성하여 서버에 저장할 수 있도록 하는 기능

**구현 내용:**
- **Route DTO 클래스 생성** (`Route.java`): 여행 루트 데이터를 담는 DTO를 정의하였습니다. `routeNum`(경로 식별 번호), `userNum`(사용자 번호), `title`(제목), `state`(상태 — 소개/모집 등), `participantCount`(참가자 수), `picture`(대표 사진), `createDate`(생성일), `startDate`(시작일), `endDate`(종료일) 필드를 포함합니다. Lombok 어노테이션(`@Getter`, `@Setter`, `@Builder`, `@ToString` 등)을 사용하여 보일러플레이트 코드를 줄였습니다.
- **RouteController에 POST 엔드포인트 구현** (`RouteController.java`): `POST /routes` 엔드포인트에서 `@RequestBody`로 `Route` 객체를 받아 `RouteService.createRoute()`를 호출합니다.
- **RouteService / RouteServiceImpl** (`RouteService.java`, `RouteServiceImpl.java`): 서비스 인터페이스에 `createRoute(Route route)` 메서드를 선언하고, 구현체에서 `RouteMapper.createRoute()`를 호출하여 DB에 저장합니다.
- **RouteMapper 및 MyBatis XML** (`RouteMapper.java`, `route.xml`): MyBatis Mapper 인터페이스에 `createRoute` 메서드를 정의하고, SQL XML에서 `INSERT INTO ROUTE` 쿼리를 작성하였습니다. MariaDB의 `UUID()` 함수를 사용하여 `ROUTE_NUM`(경로 식별 번호)을 자동 생성하는 `<selectKey>` 구문을 포함합니다.

**API:** `POST /routes` — 여행 루트 생성

---

### 2. 여행 루트 단건 조회 기능 (`#17` — `d213a22`)

**목적:** 특정 여행 루트의 상세 정보를 루트 번호로 조회하는 기능

**구현 내용:**
- **RouteEntity 생성** (`RouteEntity.java`): DB 테이블 컬럼과 1:1 매핑되는 Entity 클래스를 새로 만들었습니다. DB 컬럼명이 snake_case이므로 Entity 필드도 `route_num`, `user_num` 등으로 작성하였습니다.
- **Convertible 인터페이스 구현** (`Route.java`): `Route` DTO에 `Convertible<RouteEntity, Route>` 인터페이스를 구현하여 `toDTO(RouteEntity entity)` 메서드로 Entity → DTO 변환 로직을 작성하였습니다. Builder 패턴을 이용해 각 필드를 매핑합니다.
- **RouteController GET 엔드포인트** (`RouteController.java`): `GET /routes/{routeNum}` 엔드포인트를 구현하여 경로변수로 `routeNum`을 받고, `routeService.getRouteByRouteNum()`을 호출하여 루트 1건을 반환합니다.
- **RouteServiceImpl** (`RouteServiceImpl.java`): `getRouteByRouteNum()` 메서드에서 Mapper 호출 후 `new Route().toDTO()`로 Entity를 DTO로 변환하여 반환합니다.
- **MyBatis XML** (`route.xml`): `SELECT` 쿼리로 `ROUTE_NUM`이 일치하는 루트 1건을 조회합니다. `resultType`을 `routeEntity` alias로 설정하였습니다.
- **MyBatis modelConfig** (`modelConfig.xml`): `routeEntity` 타입 alias를 등록하였습니다.

**API:** `GET /routes/{routeNum}` — 루트 상세 조회

---

### 3. 여행 루트 목록 조회 (상태 및 정렬 기능) (`#18` — `8792998`)

**목적:** 루트를 상태(`state`)별로 필터링하고, 정렬 조건(`sortType`)에 따라 정렬하여 목록을 조회하는 기능

**구현 내용:**
- **RouteController 수정** (`RouteController.java`): `GET /routes` 엔드포인트의 파라미터를 `state`(기본값 0)와 `sortType`으로 변경하고, 반환 타입을 `List<Route>`로 수정하였습니다.
- **RouteMapper** (`RouteMapper.java`): `getRoutes(@Param("state") int state, @Param("sortType") String sortType)` 메서드를 추가하였습니다.
- **RouteServiceImpl** (`RouteServiceImpl.java`): `getRoutes(int state, String sortType)` 메서드에서 Mapper를 호출하고, 조회된 `List<RouteEntity>`를 `List<Route>` DTO로 변환하여 반환합니다.
- **MyBatis XML** (`route.xml`): 동적 SQL(`<choose>`, `<when>`, `<otherwise>`)을 사용하여 정렬 조건을 처리합니다:
  - `sortType == 'date'` → `ORDER BY CREATE_DATE DESC` (최신순)
  - `sortType == 'participantsDesc'` → `ORDER BY PARTICIPANT_COUNT DESC` (참가자 많은순)
  - `sortType == 'participantsAsc'` → `ORDER BY PARTICIPANT_COUNT ASC` (참가자 적은순)
  - 기본값 → `ORDER BY CREATE_DATE DESC`

**API:** `GET /routes?state={state}&sortType={sortType}` — 상태별·정렬별 루트 목록 조회

---

### 4. 여행 루트 검색 기능 (`#19` — `5987268`)

**목적:** 제목(`title`)과 내용(`content`)으로 여행 루트를 검색하는 기능

**구현 내용:**
- **RouteController** (`RouteController.java`): `GET /routes/search?title={title}&content={content}` 엔드포인트를 구현하였습니다. 제목과 내용을 옵셔널 파라미터로 받아 `routeService.searchRoutes()`를 호출합니다.
- **Route DTO에 리스트 변환 메서드 추가** (`Route.java`): `toDTO(List<RouteEntity>)` 메서드를 추가하여 Entity 리스트를 DTO 리스트로 일괄 변환하는 유틸리티 메서드를 제공합니다.
- **RouteMapper** (`RouteMapper.java`): `searchRoutes(@Param("title") String title, @Param("content") String content)` 메서드를 추가하였습니다.
- **RouteServiceImpl** (`RouteServiceImpl.java`): `searchRoutes()` 메서드에서 Mapper를 호출하고 Entity → DTO 변환 후 반환합니다.
- **MyBatis XML** (`route.xml`): `WHERE 1=1` 기본 조건에 `<if>` 동적 SQL로 제목 LIKE 검색(`TITLE LIKE CONCAT('%', #{title}, '%')`)과 내용 LIKE 검색(`CONTENT LIKE CONCAT('%', #{content}, '%')`)을 조건부로 추가합니다.

**API:** `GET /routes/search?title={title}&content={content}` — 루트 제목/내용 검색

---

### 5. 사용자별 여행 루트 조회 기능 (`#20` — `62a6d8f`)

**목적:** 특정 사용자가 작성한 여행 루트 목록을 조회하는 기능

**구현 내용:**
- **UserRouteController 수정** (`UserRouteController.java`): `GET /users/{userNum}/routes` 엔드포인트를 구현하여 사용자 번호(`userNum`)에 해당하는 루트 목록을 반환합니다. `RouteService.getRoutes(userNum)`을 호출합니다.
- **RouteMapper** (`RouteMapper.java`): `getRouteByUserNum(@Param("userNum") String userNum)` 메서드를 추가하였습니다.
